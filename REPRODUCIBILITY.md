# Reproducibility guide

The public repository is a curated publication copy of the cumulative gravitational-CDL derivation archive.

## Core sequence

1. **Corrected flat O(4) anchor** — `reference/o4/O4_CLEAN_DERIVATION.md`
2. **Exact scalar–tensor equations** — `derivation/GCDL_1A_EXACT_COUPLED_EUCLIDEAN_EINSTEIN_SCALAR_DERIVATION.md`
3. **Independent gravitating-background reproduction** — `derivation/GCDL_2A_INDEPENDENT_NUMERICAL_CDL_REPRODUCTION.md`
4. **Action ordering** — `derivation/GCDL_2B_GRAVITATING_ACTION_DOMINANCE_AND_COMPETING_SADDLES.md`
5. **Physical spectrum** — `derivation/GCDL_2C_PHYSICAL_SCALAR_METRIC_FLUCTUATION_SPECTRUM.md`
6. **Lorentzian continuation** — `derivation/GCDL_3A_LORENTZIAN_CONTINUATION_AND_INTERIOR_COSMOLOGICAL_BACKGROUND.md`
7. **Final verdict** — `derivation/GCDL_4_FINAL_GRAVITATIONAL_VERDICT.md`

## Environment

Recommended: Python 3.10+, numpy, scipy, sympy, pandas.
